Application Name: GeoGame

Application Description: A guessing game where it gives the user fun facts about a place, country, or region, and the user has to guess what the name of that place is. There will be difficulty levels, and depending on each, there will be more or less clues for each question. 
The database will store user information, such as username and password, their score, their friends list, and other achievements.

Audience: Students who have an intrest in facts about different parts of the world. 
This is also an educational game for kids.

Vision Statement: For students and general kids who love facts and tidbits about the world. 
GeoGame is an application where kids (or anyone) can play to not only cure boredom, but also learn 
more about the world they live in. Unlike many of the geogaphy games out there on the internet, 
this game challenges the player to connect facts to its respective place.

Communication Plan: We plan to use discord for this project as it can be organized and versatile

Extra Credit: 
    1) Enough data: Because of the amount of data needed for each country, it may be difficult to include everything for each country. 
    Mitigation Strategy: Rather than mapping the whole world and all its countries, we could scale it down to a region or continent
    2) User email sharing: there could be leaks for personal information 
    Mitigation Strategy: We could use only the username and password so emails won't be leaked/tied to a password.
    3) Levels: Each country is unique, and how difficult the facts and hint should be can vary. 
    Mitigation Strategy: We could select from a smaller pool handpicked questions and hints or general category the can be taken away each level for difficulty       (eg. flags)
    4) Country Size: Many countries are very small and not be visible to the user.
    Mitigation Strategy: A zoom feature can be added to the map or we can put less emphasis on users visually seeing a map.
    5) Internet Traffic Overflow: Too many people on the server can cause it to go down or crash
    Mitigation Strategy: The server we are hosting on can be upgraded or potentially a wait list can be added so the number of users playing is limited.
